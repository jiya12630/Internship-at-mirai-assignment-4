# 🎨 AI Image Studio

An AI-powered image generation application built with Streamlit and Pollinations AI.

## ✨ Features

- 🎨 Multiple art styles
- ↔️ Adjustable image width
- ↕️ Adjustable image height
- ✨ Magic Enhance for improving prompts
- 🎲 Surprise Me! random prompt generator
- ⬇️ PNG image download
- 🖥️ Simple and user-friendly Streamlit interface

## 🚀 Assignment 4 Enhancements

This project was upgraded as part of the MirAI School of Technology Virtual Summer Internship 2026.

### Task 1: Fixed Width & Height Sliders

The width and height values are now passed directly to the image-generation URL:

`?width=...&height=...`

This allows users to control the dimensions of generated images.

### Task 2: PNG File Extension

Downloaded images are saved with a `.png` extension.

The filename is also generated dynamically according to the selected art style.

Example:

`digital_art_ai_image.png`

### Task 3: Magic Enhance

Users can enable **✨ Magic Enhance** from the sidebar.

When enabled, the application automatically adds:

- masterpiece
- 8k resolution
- highly detailed
- trending on artstation
- unreal engine 5 render

to the image prompt.

### Task 4: Surprise Me!

The **🎲 Surprise Me!** button randomly selects one of five creative prompts and immediately generates an image.
